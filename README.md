# Паспорт проекта

## Общие сведения

**Название команды:**  Второгодники
**Название продукта:**  Система для рецензирования документов
**Коды участников:** `M1`, `M2`, `M3` 
**Статус ранней калибровки:** `черновик`

## 1. Назначение

*В двух-четырёх предложениях объясните, какую задачу решает продукт, кто получает результат и в чём состоит собственная предметная логика приложения.*
Система для рецензирования документов. Автор отправляет заявку на рецензирование и документ в систему. Один из рецензентов берёт документ на рассмотрение, проверяет документ, оставляет коментарий, отправляет на доработку. Автор получает коментарий, исправляет документ и снова отправляет его в систему. Рецензент принимает правки, документ получает статус "проверенный".

## 2. Граница продукта

**В продукт входит:**
Серверная часть данного приложения, а именно:
авторизация пользователя, отправка заявок на рецензию (автор), отправка коментария на заявку (рецензент), повторная заявка на рецензию (автор), утверждение документа как окончательного (рецензент).

**Внешнее окружение и внешние системы:**
Внешнее хранилище файлов, аунтефикация

**Команда сознательно не реализует:**
Фронтэнд приложения, хранилище файлов (S3 bucket или подобное), аунтефикация (vk_id или подобное)
