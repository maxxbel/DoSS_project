# Требования безопасности

| ID | Требование | Критерий приёмки | Связанные T / D (позднее) |
| --- | --- | --- | --- |
| SR-01 | Автор может просматривать только созданные им самим заявки. | При обращении к идентификатору чужой заявки система отклоняет запрос и не возвращает её содержимое. При обращении за своей заявкой возвращается её содержимое. | — |
| SR-02 | Рецензент может просматривать заявки, где он является рецензентом, а также заявки у которых не присвоен рецензент. | При обращении к идентификатору запрещённой заявки система отклоняет запрос и не возвращает её содержимое. При обращении за разрешённой заявкой возвращается её содержимое. | --- |
| SR-03 | Функции администратора не доступны автору и рецензенту, доступны администратору. | При обращении к функциям администратора с неправильной ролью система отклоняет запрос. Администратор может пользоваться этими функциями. | --- |
| SR-04 | Для неаунтефицированного пользователя единственная доступная функция -- вход в систему | Функция входа в систему доступна. Если пользователь неаунтефицирован, то любые другие функции системы отклоняют запрос, не раскрывая её устройство. | --- |
| SR-05 | Пароль должен быть больше 8 символов, содержать символы пунктуации, цифры и латинские буквы разных регистров | При обращении к функции регистрации с неподходящим паролем система возвращает ошибку и сообщение с требованиями к паролю. При соответствии требованиям регистрация проходит успешно. | --- |
| SR-06 | Автор не может рецензировать заявки | При обращении к функции рецензирования система отклоняет запрос. При обращении к этой функции закреплённого за заявкой рецензента система запрос выполняет. | --- |
| SR-07 | Рецензент не может загружать в заявку документ | При обращении к функциям, позволяющим загружать документы, система отклоняет запрос. При обращении к этим функциям автора заявки система выполняет запрос. | --- |
| SR-08 | Заявку в статусе "в работе" нельзя дорабатывать | При обращении к функции доработки автором заявки в статусе "в работе" система отклоняет запрос. Данные функции доступны для автора заявки в статусе "на доработке". | --- |
| SR-09 | Заявку в статусе "на доработке" нельзя закрыть или оставить не неё рецензию | При обращении к функциям рецензирования рецензентом заявки в статусе "на доработке" система отклоняет запрос. Данные функции работают с заявками в статусе "в работе" для рецензента, присвоенного заявке. | --- |
| SR-10 | К закрытой заявке нельзя добавлять комментарии, менять итоговый документ, с ней ассоциированный | При обращении к любым функция рецензирования и редактирования к закрытой заявке система отклоняет запрос. | --- |
